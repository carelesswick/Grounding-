# BigModel 项目阶段汇报

## 1. 项目目标

基于课题组桥梁病害数据，对 **LocateAnything-3B** 进行领域微调，实现无人机/桥梁巡检图像中的病害目标定位，支持后续 Agent 调用 Grounding Tool 完成检测与报告生成。

## 2. 数据情况

- 图片来源：课题组桥梁巡检图像
- 图像分辨率：4000 × 3000
- 训练图：339 张
- 验证图：85 张
- 类别：7 类

| 类别 | 训练框数 |
|---|---:|
| coating_rusting | 505 |
| railing_rusting | 107 |
| nut_rusting | 77 |
| coating_peeling_off | 30 |
| coating_dirty | 26 |
| nut_missing | 20 |
| nest | 2 |

## 3. 技术方案

- 基座模型：`nvidia/LocateAnything-3B`
- 微调方式：LoRA（rank=16）
- 冻结策略：冻结 LLM + Backbone，训练 MLP + LoRA
- 数据策略：
  - 800×800 tile 切图，重叠率 20%
  - 小目标额外 crop
  - 训练样本：1056 tile + 100 crop（repeat_time=2）
- 训练环境：单张 RTX 3090

## 4. 训练过程

| 步数 | train_loss | 说明 |
|---|---:|---|
| 200 | 1.2604 | 初版跑通 |
| 600 | 0.7056 | 明显下降 |
| 1000 | 0.3652 | 继续提升 |
| 1500 | 0.2791 | 继续提升 |
| 2000 | 0.1890 | 当前最优 |
| 2500 | 0.1790 | 基本收敛 |

> 2000 步后验证指标不再明显提升，选择 2000 步作为最终模型。

## 7. 当前问题
